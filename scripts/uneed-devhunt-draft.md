## Description courte (~150-200 caractères, champ résumé)

JSON Tools is a set of 28 free developer utilities (formatter, diff, JWT decoder, converters, regex tester and more) that run entirely in your browser. Nothing you paste is sent anywhere.

## Description longue (champ "about" / détail)

JSON Tools started as a JSON formatter built to practice Nuxt 4, and grew into 28 small utilities: JSON diff and tree viewer, schema generator, JWT decoder and generator, CSV/XML/YAML/Excel converters, regex tester, SQL formatter, hash and UUID generators, and a few others.

Every tool runs client-side. The site is a static build with no backend, so there's nothing to sign up for and nothing that could store what you paste.

Built out of frustration with single-purpose tool sites that bury a ten-second task behind ads or a signup wall.
